### Projetos

**Sistema de Ponto Eletrônico** — *repositório privado*
Sistema de registro de ponto desenvolvido de ponta a ponta para a VMac Engenharia, substituindo a solução anterior em no-code.
`Python/FastAPI` `SQLAlchemy` `JWT` `Flutter (Android/iOS/Web)` `Firebase` `Docker` `Nginx`
Marcação de entrada/saída/pausas com geolocalização, dashboard de horas normais e extras, histórico e exportação de folha em PDF/Excel.

**Automação geoespacial (VMac)** — *repositório privado*
Pipelines SHP + Excel → KML com GeoPandas, Shapely e SimpleKML, integração com a API GeoSampa (WFS), cruzamento com malhas viárias (OSM/IBGE) e matching de logradouros com taxa de erro reduzida para 2%–7%.

**Plataforma Vanep** — *produto privado*
API Java 25 / Spring Boot 4 (OAuth2 + PKCE, RBAC, Flyway), web Next.js 16 + React 19 e app Flutter em arquitetura BLoC.
